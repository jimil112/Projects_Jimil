# Template Repository for COMP SCI 2207/7207 Web & Database Computing (2023 Semester 1)

Contains environment files for WDC 2023. Copy this template for a general sandbox.

Auto commit/push/sync to Github is disabled by default in this template repository.
Enable the GitDoc extension to use this fucntionality (either in your VSCode settings, or in the Dev Container settings)

Hi. This is our readMe file.

To start,

npm start - which will ask you to open in browser on port 3000.

http://localhost:3000/Home_page/Home_page.html - Then copy and paste this to open up the homepage, from here you can view the whole website


Note (If needed):
npm install - to download all the dependencies

Individually you can download the files.

npm install body-parser
npm install cookie-parser
npm install cors
npm install debug
npm install express
npm install express-session
npm install morgan
npm install mysql
npm install nodemailer
npm install passport
npm install passport-google-oauth20
